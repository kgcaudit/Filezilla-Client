# OLO Explorer — 실기기 스모크 테스트 체크리스트

리팩터링(P3 컨트롤러 분리, 엔진 통합) 이후 **회귀가 없는지** 사람이 실기기에서
한 바퀴 확인하기 위한 목록이다. 자동 테스트가 못 잡는 것 — 실제 서버 접속, 실제
파일 전송, 화면 전환, 권한·저장공간 같은 경계 상황 — 에 집중한다.

- 대상 빌드: 서명된 릴리즈 APK(`app-release.apk`) 또는 디버그 설치본.
- 한 항목이라도 어긋나면 그 자리에서 기록(스크린샷 + 재현 절차)하고 공유.
- 순서는 권장 흐름일 뿐, 독립적으로 확인해도 된다.

---

## 0. 설치·기동
- [ ] 설치 후 첫 실행에서 **크래시 없이** 첫 화면이 뜬다.
- [ ] 저장소 접근 권한 안내(StorageGate)가 기기 OS 버전에 맞게 뜬다
      (Android 11+ = 모든 파일 접근 설정, 그 이하 = 런타임 권한).
- [ ] 권한 허용 후 로컬 파일 목록이 보인다.

## 1. 로컬 파일 탐색
- [ ] 좌/우 두 창에서 각각 폴더를 열고 들어가고 나온다(뒤로 가기 포함).
- [ ] 정렬·숨김파일 토글이 반영된다.
- [ ] 필터 바를 열고 글자를 입력하면 즉시 걸러지고, 닫으면 필터가 사라진다.
- [ ] 북마크 추가 → 다른 창에서 그 북마크로 이동이 된다.

## 2. 서버 접속 (FTP / FTPS / SFTP 각각)
각 프로토콜로 사이트를 하나씩 만들어 반복한다.
- [ ] **FTP** 접속 → 루트 목록이 뜬다.
- [ ] **FTPS** 접속 → (처음이면) 인증서 신뢰 질문이 뜨고, 신뢰하면 목록이 뜬다.
- [ ] **SFTP** 접속 → (처음이면) 호스트키 신뢰 질문이 뜨고, 신뢰하면 목록이 뜬다.
- [ ] 한번 신뢰한 사이트는 다시 물어보지 않는다(핀 저장 확인).
- [ ] 한글/공백/특수문자가 든 폴더·파일 이름이 깨지지 않는다.
- [ ] 깊은 폴더로 들어갔다가 루트까지 뒤로 나온다.

## 3. 전송 — 다운로드/업로드 + 재개(resume)
- [ ] 서버 파일 1개 다운로드 → 로컬에 생기고 내용이 온전하다.
- [ ] 로컬 파일 1개 업로드 → 서버에 생긴다.
- [ ] **폴더 통째로** 다운로드/업로드(하위까지) 된다.
- [ ] 큰 파일 전송 중 **일시정지 → 재개** 시 이어받기(중복 바이트 없이 완료).
- [ ] 전송 중 **취소**하면 큐에 "취소/실패"로 표시되고 앱이 멎지 않는다.
- [ ] 동시 2건 전송이 큐에서 각각 진행률로 보인다.
- [ ] 같은 이름 파일 전송 시 **덮어쓰기/건너뛰기/양쪽 유지** 선택이 뜨고 선택대로 된다.
- [ ] 전송 완료 후 해당 폴더를 보고 있던 창이 자동으로 새 파일을 반영한다.

## 4. 전송 큐 화면
- [ ] 완료/실패/대기 항목이 구분되어 보인다.
- [ ] "완료된 항목 삭제"가 완료만 지운다.
- [ ] 진행 중인 항목이 있을 때만 "목록 비우기"가 보인다(없으면 숨김).
- [ ] 전체 일시정지 / 전체 시작이 동작한다.

## 5. 휴지통 (로컬 삭제) — *P3에서 분리된 영역, 특히 확인*
- [ ] 로컬 파일 삭제 → 휴지통으로 이동(영구삭제 아님).
- [ ] 휴지통 화면에 삭제 시각 그룹(오늘/어제/이전)으로 보인다.
- [ ] 항목 **복원** → 원래 위치로 돌아오고, 그 폴더를 보던 창에 즉시 나타난다.
- [ ] 원래 위치에 같은 이름이 생겼을 때 복원하면 **덮어쓰지 않고** 다른 이름으로 들어온다.
- [ ] 선택 모드: 여러 개 선택 → 일괄 복원 / 일괄 영구삭제.
- [ ] "휴지통 비우기" → 전부 영구 삭제.
- [ ] 같은 이름 파일을 서로 다른 폴더에서 삭제해도 둘 다 휴지통에 남는다.

## 6. 뷰어
- [ ] **이미지**: 폴더의 사진을 열어 좌우로 넘긴다(만화/웹툰 모드 포함).
- [ ] **사진 정보(EXIF)** 시트 — *P3에서 분리된 영역*:
  - [ ] 로컬 사진에서 촬영정보가 보이고 **회전/위치삭제/전체삭제**가 먹힌다(회전 후 화면 갱신).
  - [ ] 서버에서 받은(캐시) 사진은 **편집 불가(읽기전용)** 로 표시된다.
- [ ] **체크섬** — *P3에서 분리된 영역*: 파일 체크섬 계산 → 진행률 후 해시 표시,
      알고리즘(SHA-256/SHA-1/MD5) 바꾸면 다시 계산.
- [ ] **PDF / EPUB / 텍스트 / 미디어(동영상·오디오)** 각각 열려서 재생/표시되고,
      마지막 위치(페이지/챕터/재생시점)를 기억한다.

## 7. 압축/해제
- [ ] zip/일반 아카이브를 열어 내부를 보고, 안의 이미지를 뷰어로 연다.
- [ ] 선택 항목 압축 / 아카이브 해제가 된다.

## 8. 폴더 동기화 / 예약 동기화 — *P3에서 분리된 영역*
- [ ] 수동 폴더 미러: 스캔 → 미리보기 → 확인 → 실행 순서로 동작, 삭제는 기본 꺼짐.
- [ ] 예약 동기화 작업 추가/수정/켜고끄기/삭제/즉시실행이 된다.
- [ ] 예약 작업이 조건(Wi-Fi/충전)에 맞게 등록된다.

## 9. 경계 상황 (크래시·데이터 안전) — *A③ 관련*
- [ ] **저장공간 부족**: 용량이 거의 찬 상태에서 큰 파일을 로컬로 복사/다운로드하다
      실패시키면, **반쯤 쓰인 파일이 남지 않고** 큐/화면에 실패로 보인다.
- [ ] **권한 거부**: 저장소 권한을 거부했을 때 앱이 멎지 않고 안내 화면이 뜬다.
- [ ] **큰 폴더 작업 취소**: 많은 파일 복사/전송/검색 중 취소해도 앱이 멎지 않고
      부분 결과가 거짓(완전한 척) 없이 정리된다.
- [ ] **오프라인**: 네트워크가 끊긴 상태에서 서버 접속 시 "연결할 수 없음" 류 메시지가
      뜨고 멎지 않는다.
- [ ] **서버 측 재귀 삭제 과대**: 아주 큰 트리 삭제 시 "한 번에 너무 많음" 안내로
      안전하게 막힌다.

## 10. 화면 전환·상태 유지
- [ ] 홈 ↔ 큐 ↔ 휴지통 ↔ 설정 전환이 매끄럽다.
- [ ] 화면 회전/백그라운드 복귀 후에도 창 위치·목록이 유지된다.
- [ ] 당겨서 새로고침(Pull-to-refresh) 인디케이터가 매번 올라오고 다시 내려간다.
